# Dotfiles

Personal configuration files from `~/.config`.

## What's here

- `nvim/` — NvChad-based Neovim setup with the `penumbra_dark` theme, options, mappings, and plugin configuration.
- `wezterm/` — WezTerm settings with a Penumbra-like custom palette layered over the Catppuccin Mocha base scheme, plus fonts and key bindings.
- `starship/` — Starship prompt configuration.
- `gh/config.yml` — GitHub CLI preferences; authentication credentials are kept local.
- `opencode/` — OpenCode UI and TUI settings.
- `tanstack/` — TanStack CLI settings.

The `.gitignore` omits machine-specific state, authentication data, histories, installed extensions, and dependency directories.
